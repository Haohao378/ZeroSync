# ZeroSync: 本地AI远端服务器操作引擎

ZeroSync 是一款高性能跨平台实时同步软件，专为 AI 驱动的现代化开发流程设计。它能够将本地开发环境与远端服务器无缝映射，并通过动态技能注入机制，赋予本地各类 AI 智能体（如 Gemini CLI, Claude Code, codex 等）无感操作远程服务器，彻底打破本地与云端的边界。

## 核心优势

*   **全协议兼容，智能体无感接入**：不绑定特定 AI，通过标准化的技能注入与 Python 工具链，可完美适配市场上绝大多数具备外部工具调用能力的 AI Agent。
*   **极致隐私，完全本地化**：您的对话历史、智能体配置、提示词逻辑以及所有的隐私数据**全部保留在本地**。ZeroSync 仅充当底层“操作手”，将指令安全传递至远端。
*   **深层次云端编排**：AI 智能体可彻底无隔阂地操作远端服务器。它能完全利用自身携带的工具链实现自动化代码编写、实时任务部署与环境管理，如同 AI 本身就运行在远端环境之中。
*   **无感服务器端 Vibe Coding**：凭借超快的同步响应速度，您可以像本地 AI 编程一样，直接驱动 AI 智能体对远端服务器进行“氛围编程”。无论是自动化环境部署、Debug 排查还是日常编程操作，一切交互体验均与本地开发完全等同，彻底消除云端开发的“隔阂感”。

## 快速开始

### 1. 克隆仓库与依赖安装

```bash
# 克隆项目
git clone https://github.com/Haohao378/ZeroSync.git
cd ZeroSync

# 创建并激活虚拟环境 (建议)
conda create -n zerosync python=3.10
conda activate zerosync

# 安装核心依赖
pip install -r requirements.txt
```

### 2. 编译通信协议
ZeroSync 使用 gRPC 进行高效的数据传输，首次使用需要编译协议文件。
需激活您安装了依赖的 Conda 环境：`conda activate zerosync`。

*   **Windows 用户**：
    执行编译脚本：
    ```powershell
    # 运行脚本
    .\protos\build.bat
    ```
*   **macOS 用户**：
    在终端执行以下指令：
    ```bash
    # 赋予执行权限
    chmod +x protos/build.sh

    # 运行脚本
    ./protos/build.sh
    ```

### 3. 启动图形化管理界面
```bash
python main_gui.py
```
启动后，请参照 **[详细使用说明书](Product_Manual.md)** 或程序内的 UI 提示，依次完成“服务器配置”与“智能体助手”的配置。

## 技术原理：本地 AI 如何实现无感服务器操控？

ZeroSync 通过两个核心层级的协作，在本地 AI 智能体与远端服务器之间构建了一个透明的“能力映射”：

### 1. 同步层：环境的一致性映射
同步层的作用是让本地与远端在“物理空间”上保持重合。
当本地 AI 智能体使用其原生的文件编辑工具修改本地代码时，同步层会确保这些改动实时在服务器上同步生效。
**这带来的结果是：** AI 智能体无需学习任何远程传输协议，它只需像平常操作本地项目一样编写代码，服务器上的运行环境就会自动对齐。

### 2. 技能层：核心能力的无缝注入
技能层通过在智能体目录中注入 **4 个核心工具脚本**，为其提供了操作远端环境的专用接口：
*   **远程执行**：接管智能体的 Shell 权限，使其指令直接作用于远端 PTY 终端。
*   **环境探测**：让智能体一键掌握远端 GPU、内存、磁盘等硬件实时状态。
*   **安全拉取**：赋予智能体回传远端生成文件（如权重、日志）的能力，且不会导致同步冲突。
*   **网络击穿**：自动将远端（甚至 Docker 内部）的服务端口映射至本地。

### 总结
**同步层**负责“同步大脑修改后的代码”，**技能层**负责“提供操作远端的肢体”。通过这两者的结合，本地运行的 AI 智能体能够完全忽略物理空间的隔阂，直接使用其自身的逻辑工具链对远端服务器进行高效编排，实现真正的无感 Vibe Coding。
